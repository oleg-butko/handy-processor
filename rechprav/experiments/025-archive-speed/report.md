# 025: ускорение архива исходников

2026-09-23, baseline `43120b4`, ветка `perf/source-archive-compression`.

После включения dictionary.rpt в исходный ZIP максимум DEFLATE 9 стал
основным потребителем времени. Сравнён полный allowlist исходников с этим же
словарём; после записи каждого архива выполнялась штатная проверка манифеста,
CRC всех файлов и сгенерированного номера сборки.

Команда воспроизведения:

```bash
PYTHONDONTWRITEBYTECODE=1 python3 rechprav/scripts/benchmark_source_archive.py rechprav/experiments/025-archive-speed/levels.json
```

| Уровень | Запись, с | Проверка, с | Всего, с | Размер, МиБ |
|---|---:|---:|---:|---:|
| 1 | 1,82 | 0,64 | 2,46 | 31,16 |
| 3 | 3,14 | 0,57 | 3,71 | 29,42 |
| 6 | 7,22 | 0,47 | 7,70 | 27,08 |
| 9 (прежний) | 50,65 | 0,58 | 51,23 | 27,15 |

Выбран уровень 1: в этом замере примерно в 21 раз быстрее прежнего,
архив на 4 МиБ (15%) больше. Уровень 6 подходит при приоритете размера,
но для частой передачи исходников между VM и Windows выбран самый быстрый
из измеренных. Уровень 9 не дал выигрыша даже в размере на этом наборе.
Кеш сжатого словаря и отдельный архив ресурсов не понадобились: полный ZIP
остаётся самостоятельным, правила его распаковки не меняются.

Это один последовательный замер каждого уровня на текущей Debian VM,
не статистическая оценка для любых машин/дисков. Сжатие осталось стандартным
ZIP DEFLATE; проверки целостности не отключались. Алгоритм коррекции не менялся.

[Исходные замеры](levels.json). Итоговая обычная команда
`npm run archive:sources` заняла **2,894 с**, включая запуск npm/Python и
штатную проверку ZIP: [вывод](final-command.txt).
Готовый архив также распакован существующим Windows unpacker во временный
каталог, SHA256 каждого исходного файла сравнен с оригиналом, полный словарь
на месте: [проверка](verification.json).
