# Архив исходников

Создать ZIP-архив с исходниками можно из корня репозитория:

```bash
npm run archive:sources
```

Команда создаёт файл с временной меткой:

```text
archive/handy-processor-sources-YYYYMMDD-HHMMSS.zip
```

Используется жёсткий белый список исходных каталогов и файлов. В архив не
попадают `.git`, `node_modules`, `dist`, `web-dist`, `sea-build`, Rust
`target`, launcher sidecar binaries, SQLite-базы и ранее созданные архивы.
Файл ручной major-версии `version-major.txt` входит в архив. Дополнительно
скрипт вычисляет текущий commit count и создаёт непосредственно внутри ZIP файл
`version-build.txt`. Поэтому launcher можно собирать после распаковки без
каталога `.git` и без ручной переменной окружения.

Перед завершением команда сравнивает фактическое содержимое ZIP с собранным
манифестом и проверяет целостность каждого файла. Если обязательный исходный
путь отсутствует, архив не создаётся.

Используется быстрый уровень ZIP DEFLATE 1. В замере на текущем комплекте
исходников и словаря это сократило создание и проверку с 51,2 до 2,5 секунды;
размер вырос с 27,1 до 31,2 МиБ. Время зависит от машины и диска. Состав архива,
проверка целостности и совместимость с Windows-распаковщиком сохранены.
Сравнение уровней 1/3/6/9: [результаты замеров](../../rechprav/experiments/025-archive-speed/report.md).

Для Windows-коррекции архив включает исходники `rechprav`, Cargo.lock, стартовые
TOML-профили и подготовленный платформонезависимый ресурс
`rechprav/artifacts/opencorpora-wordfreq/dictionary.rpt` (около 118 МиБ до сжатия).
Этот генерируемый словарь не хранится в Git: перед созданием архива он должен
существовать локально. Python-окружение подготовки ресурсов, кеши, частотные
таблицы и приватные корпуса в ZIP не входят. Windows-worker собирается на
Windows; Linux binary в архив не включается.

Подготовка словаря и зависимостей worker описана в
[инструкции коррекции](../rechprav/handy-integration.md#windows-portable-и-ошибка-enoent).

Для команды нужен Python 3. Дополнительные Python-пакеты и системная утилита
`zip` не требуются.

Распаковать новый архив поверх Windows-каталога с сохранением зависимостей
можно по [инструкции обновления исходников](windows-source-update.md).
