# Архив исходников

Создать ZIP-архив с исходниками можно из корня репозитория:

```bash
npm run archive:sources
```

Команда создаёт файл с временной меткой:

```text
archive/handy-processor-sources-YYYYMMDD-HHMMSS.zip
```

Используется жёсткий белый список исходных каталогов и файлов. В архив не
попадают `.git`, `node_modules`, `dist`, `web-dist`, `sea-build`, Rust
`target`, launcher sidecar binaries, SQLite-базы и ранее созданные архивы.
Файл ручной major-версии `version-major.txt` входит в архив. Дополнительно
скрипт вычисляет текущий commit count и создаёт непосредственно внутри ZIP файл
`version-build.txt`. Поэтому launcher можно собирать после распаковки без
каталога `.git` и без ручной переменной окружения.

Перед завершением команда сравнивает фактическое содержимое ZIP с собранным
манифестом и проверяет целостность каждого файла. Если обязательный исходный
путь отсутствует, архив не создаётся.

Для команды нужен Python 3. Дополнительные Python-пакеты и системная утилита
`zip` не требуются.

Распаковать новый архив поверх Windows-каталога с сохранением зависимостей
можно по [инструкции обновления исходников](windows-source-update.md).
