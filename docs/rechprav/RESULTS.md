# Результаты Rechprav

Обновлено: 2026-09-19. Работают подготовка корпуса, просмотр, KEEP и baseline B1:
OOV + trie + обычный Levenshtein=1 + единственный кандидат. Проведено первое
сравнение защит. Победитель для реального ASR не выбран; по выбору пользователя
пока используются технические примеры.

| Проверка | Результат |
|---|---|
| Текущий pipeline | TypeScript, синхронный реестр правил |
| Существующая близкая функция | Ограниченная коррекция русских числительных |
| История | ASR-вход и результат правил; ручного gold это не даёт |
| Размеченные данные | Пользователь подтвердил: пары пока не подготовлены; разметка входит в первый этап |

| Первичные источники | SymSpell/FST доступны; OpenCorpora не удалось прочитать |
| Технические данные | 67 tokenizer fixtures, исходный корпус 12 записей и расширенный 27 |
| Проверки | 35 тестов, clippy без предупреждений, rustfmt, offline release build |
| Качество и производительность коррекции | Есть техническое сравнение B1; качество на реальном ASR и производительность индексов не оценены |

| Recall / F0.5 / FCR | 0 / 0 / 0 |
| WER до / после | 10/37 / 10/37 (27.03% / 27.03%) |

Это ожидаемые контрольные числа, не доказательство качества. Скорость алгоритмов,
RAM, recall@K и доверительные интервалы на реальных данных ещё не измерялись.
Сохранённое время evaluation включает валидацию/токенизацию/расчёт метрик;
его нельзя использовать как latency корректора.

Будущая сводка должна содержать описание corpus/split и словаря, commit/config,
TP/FP/FN/H/C, precision/recall/F0.5/F1/FCR с интервалами, WER до/после,
candidate recall@K, latency p50/p95/p99, throughput, RAM, размер и сборку индекса.
Для каждого лидера — разбор ошибок, ограничения и ablation. Формулы и порядок
выбора определены в [протоколе](experiment-protocol.md).

Не заполнять будущие сравнения ожидаемыми числами. Пока нет реальных измерений,
все выводы о превосходстве SymSpell, FST, фонетики и контекста — гипотезы.

## 002 — B1 и роль защит

[Отчёт, все девять ошибок и воспроизведение](../../rechprav/experiments/002-baseline/report.md),
[машинная таблица](../../rechprav/experiments/002-baseline/comparison.csv),
[пример исправлений](../../rechprav/experiments/002-baseline/review/review.txt).

Новый синтетический корпус: 27 записей, 62 gold tokens, 44 правильные исходные
позиции, 15 ошибок 1→1 и 2 compound spans. Словарь — 57 заданных словоформ;
это стресс-проверка, не репрезентативная выборка речи. WER до: 19/62 = 30.65%.

| Вариант | Верных / неверных правок | Precision | Испорчено правильных слов | WER после |
|---|---:|---:|---:|---:|
| KEEP | 0 / 0 | N/A | 0 | 30.65% |
| B1 со всеми защитами | 9 / 2 | 81.82% | 1 | 17.74% |
| Без domain | 9 / 3 | 75.00% | 2 | 19.35% |
| Без ignore | 9 / 3 | 75.00% | 2 | 19.35% |
| Разрешён titlecase | 10 / 3 | 76.92% | 2 | 17.74% |

Вывод: B1 полезен как исходная точка сравнения, но недостаточен для автоматической
коррекции. Единственность кандидата не защищает от пробелов в словаре.
Domain/ignore и защита заглавных слов сохранены. Следующие проверки — полноценный
словарь и частоты, затем уточнение решения «заменить / оставить». Числа выше
не переносить на настоящую историю Handy.
