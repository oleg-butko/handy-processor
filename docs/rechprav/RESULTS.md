Корректоры и benchmark ещё не реализованы; победителя нет.

| Проверка | Результат |

| Существующая близкая функция | Ограниченная коррекция русских числительных |
| История | ASR-вход и результат правил; ручного gold это не даёт |

| Rust/Cargo | Не найдены в PATH и стандартном пользовательском каталоге |
| Первичные источники | SymSpell/FST доступны; OpenCorpora не удалось прочитать |
