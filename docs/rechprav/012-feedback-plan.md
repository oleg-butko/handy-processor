# 012 — подозрительные исходные слова и обратная связь редактора

2026-09-21. Протокол до кода/замеров. Пользователь предложил учитывать ручную
замену: снижать предпочтение удалённого слова, повышать вставленное, использовать
соседей; неизвестную цель предлагать в пользовательский словарь. Пример
свод→слот / сняли свод — иллюстрация, не предоставленная реальная ASR-пара.
Взвешенная дистанция временно отложена ради проверки этого сигнала.

Разделить три механизма:
1. Source penalty: положительный штраф сохранению конкретного исходного span.
   Реализация добавляет его всем оценкам замены относительно KEEP; конкуренцию
   целей сама по себе не разрешает. Это эвристический вес, не вероятность.
2. Target boost: существующий вес термина/семьи. Не тождественен паре замены:
   повышает цель для всех её aliases. Употребление и цитирование не различает.
3. Контекст источника (штраф только в окружении) и контекст конкретной цели
   (существующий bonus/context gate) проверить отдельно, особенно при конкуренции.

Опциональные source_penalties: id, enabled, source (1–3 русских слова), penalty
0..10, context_patterns (OR, пусто = глобально). Совпадение источника точное по
нормализованным токенам, не нечёткое. До 128 правил, до 32 шаблонов у правила;
бюджет поиска учитывает проверки. При нескольких совпадениях взять максимум,
не сумму: копирование правил не усиливает оценку. Глобальный слабый штраф и
контекстный более сильный задаются двумя правилами. Старые файлы без поля не
меняют решения/диагностику. Gates, защиты, поиск aliases остаются прежними:
штраф сам не порождает кандидата и не обходит never/preserve/context/cap.

Заморозить отдельный synthetic/dev корпус: нужные свод/ввод→слот, корректные
свод правил/ввод данных, архитектурный свод, контекст сняли с двумя смыслами,
неизвестный сосед освободи, многословный источник, конфликт целей, кавычки/URL,
заглавные/перенос/пунктуация, буквальное обсуждение. Замороженные алиасы являются
явно известными парами, не обучением на независимом ASR.

Для наблюдения порога используем небольшой консервативный профиль с term boost=-2,
known always/cap=0. Сравнить baseline, только target+1, только source+2,
оба глобально (+1/+1), оба контекстно (source+1 только сняли), слабый глобальный
source=.5 + контекстный=1, source off, target off, повтор совпадающего правила,
конфликт свитч, target+1 при конфликте, контекст конкретной цели, строгий never.
Контекст известен только из иллюстративного события сняли свод→сняли слот.
Новые глаголы не добавлять после результатов. Проверить полный набор 142 старых
прогонов побайтно; новые метрики/изменения и случаи вреда считать независимо.

Будущий редактор: хранить append-only событие с id и точными before/after,
исходными диапазонами/соседями, выбранным набором/доменом, подтверждением пользователя
и идентификатором отмены. Общая правка текста не обязательно ошибка ASR: изменение
смысла/стиля нельзя превращать в обучение автоматически. Минимальный diff требует
проверки при повторяющихся словах и нескольких правках. Сначала строить отключаемое
предложение для конкретной пары/контекста; отсутствие цели в словаре означает
кандидата в термины (также возможны опечатка/имя), не доказанный новый термин.
Повторы события дедуплицировать; силу повторных подтверждений ограничивать,
поддержать отрицательные подтверждения, отмену/удаление и отдельные наборы.
Никакой необратимой правки общего русского словаря. При снятии настройки
пересчитывать эффективный профиль из активных событий, а не вычитать приблизительно.

Этот этап проверяет веса источника/цели и сохраняет пример события, но не
реализует интеграцию редактора, автоматическое принятие предложений, накопление
статистики, синхронизацию или настоящее вероятностное обучение.
