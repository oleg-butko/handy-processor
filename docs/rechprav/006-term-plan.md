# 006 — управляемые наборы терминов: протокол до замеров

Уточнение пользователя 2026-09-20: термины могут распознаваться далеко от
правильного написания, как обычные слова (`слот → свод/ввод`) или как 2–3 слова;
аббревиатура ПНЗ имеет варианты `пээнзэ`, `пэнзэ`, `пензе`, `пензэ`, `бензэ`.
Нужны отключение, независимые наборы и регулировка склонности к конкретной цели.
Это расширяет прежний план OOV-only; real-word и несколько слов включаются
в отдельный терминологический опыт, без изменения B2.

## Ограниченный первый механизм

- Отдельный терминологический проход и CLI; не включать автоматически в Handy
  или B2. Отсутствие/отключение терминов оставляет исходник без изменений.
- TOML: общий выключатель; enabled/boost у набора и термина; canonical spelling;
  список речевых вариантов; политика обычных слов never/context/always.
- Сравнить exact (явные последовательности токенов) с edit (склеенные 1–3 токена,
  обычный Levenshtein к речевым вариантам, max_distance=1, ablation=2).
  Это не обученная фонетика и не измеренная вероятность.
- Начальные баллы: 4 − distance + global/set/term boost + 2 при контексте
  − 1 при наличии известного слова. KEEP=0, минимальный перевес 3,
  перевес над другой целью 1. Все значения фиксируются до просмотра результатов.
- Контекст — заданные слова в пределах 4 соседних токенов, без пересечения
  пунктуации/переносов. Проверить как полезные контексты, так и ложные подсказки.
- Конкурентов одной цели объединять максимумом, а не суммой. При близких оценках
  разных целей KEEP; при пересечении диапазонов также учитывать неоднозначность.
- Не трогать код, URL, пути, ignore/domain, уже правильные canonical terms.
  Не склеивать через пунктуацию/переносы. Результат применяется одним проходом
  по исходным байтовым диапазонам, без каскадных замен.
- Ограничить число сравнений; при исчерпании бюджета оставить всю строку.

## Сравнения

1. disabled, exact, edit distance=1, edit distance=2;
2. edit с запретом обычных слов / с контекстным разрешением / без контекстного
   ограничения;
3. пониженный и повышенный boost ПНЗ при остальных прежних параметрах;
4. второй конфликтующий набор включён / выключен / выбран повышением приоритета;
5. прежний B2 как независимый контроль на новом наборе; старый корпус и все
   существующие тесты — регрессия, значения B2 должны остаться прежними.

Синтетический набор включает подсказанные пользователем варианты, новые близкие
варианты, 2–3 слова, правильные географические/обычные слова, одинаковые подсказки
в правильных фразах, защиты и границы. Разделять явные aliases и новые варианты
при разборе результатов. Это проверка механики и риска, не обобщение на Handy.

Отдельный span evaluator: точный TP по исходному диапазону и replacement,
FP/FN, испорченные правильные исходные позиции, exact text и WER. Несколько слов
не оценивать через zip или старые метрики только 1→1. Сохранить каждый отказ,
кандидатов, score, distance, контекст, источник набора и все несовпадения с gold.

После опыта принять только подтверждённые механизмы управления; не объявлять
пороги готовыми для автоматической вставки. Следующие гипотезы — более точный
контекст и фонетический генератор, отдельно от изменения управляющих настроек.
