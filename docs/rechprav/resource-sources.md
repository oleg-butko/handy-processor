# Ресурсы для опыта 003

Дата проверки: 2026-09-19. Экспорт не читает проверочный корпус и не добавляет
его gold в словарь. Все Python-зависимости нужны только для подготовки данных;
Rust-корректор работает локально без Python и сети.

## Словоформы

Выбран `pymorphy3-dicts-ru==2.4.417150.4580142`: пакет уже закреплён в основном
проекте для проверки числительных. Это удобный воспроизводимый снимок OpenCorpora,
а не утверждение, что словарь актуален на 2026 год. Метаданные: сборка
2022-01-08, source revision 417150, corpus revision 4580142.
Экспортируем все хранимые формы, соответствующие `[а-яё]{1,128}`, удаляем повторы.
Не используем предсказание морфологии и не фильтруем имена или редкие формы.
Проверяем порядок ключей, чтобы потоковое удаление повторов было корректным.

5 140 211 ключей с повторными разборами → 3 064 812 разных написаний →
3 022 339 допустимых для текущего токенизатора форм. 42 473 написания с дефисами,
цифрами и другими символами исключены. Нормализацию е/ё выполняет Rust при загрузке;
это дополнительно уменьшает число ключей.

Код упаковки имеет лицензию MIT, **данные — CC BY-SA 3.0**. Атрибуция:
OpenCorpora; пакет pymorphy3-dicts-ru, Danylo Halaiko.
[Описание закреплённого пакета](https://pypi.org/project/pymorphy3-dicts-ru/2.4.417150.4580142/).
У upstream есть существенная оговорка: хранимые формы могут включать распространённые
неправильные написания. Поэтому наличие формы в словаре не доказывает правильность
фразы. [Исходник обёртки словаря](https://github.com/no-plagiarism/pymorphy3/blob/master/pymorphy3/opencorpora_dict/wrapper.py).

Альтернатива изучена: русский Hunspell в LibreOffice, Alexander I. Lebedev,
отдельные `.dic` и `.aff`, собственное BSD-подобное разрешение с обязательным
сохранением уведомлений и обозначением изменений.
[README и условия](https://raw.githubusercontent.com/LibreOffice/dictionaries/master/ru_RU/README_ru_RU.txt).
В этот опыт не включён: список основ `.dic` нельзя честно сравнивать с полными
словоформами, а корректное разворачивание аффиксов требует отдельной проверки.
Решение не означает, что OpenCorpora качественнее Hunspell.

## Частоты

Выбран `wordfreq==3.1.1`, автор Robyn Speer, список `ru/large`.
713 447 записей → 668 309 написаний с тем же фильтром русских букв.
Экспорт — TSV без заголовка, `слово<TAB>частота на миллиард токенов`.
Берём `get_frequency_dict`, умножаем вероятность на 1e9, записываем 12 значащих
цифр; это оценка из частотных корзин, а не точное число наблюдений.
Известность в частотном списке **не добавляет** слово в словарь допустимых форм.
При е/ё-коллизиях используем максимум, чтобы не удвоить один и тот же сигнал.
Отсутствующая частота остаётся `None`; для формулы используется нулевой нижний
уровень. Это не свидетельство ошибочности слова.
[Документация закреплённой версии](https://pypi.org/project/wordfreq/3.1.1/).

Код — Apache-2.0; данные — CC BY-SA 4.0. Не путать лицензии.
Нужно сохранять атрибуцию Robyn Speer и уведомления источников wordfreq:
Google Books Ngrams, Leeds Internet Corpus, Wikipedia, ParaCrawl,
OPUS/OpenSubtitles, SUBTLEX (Marc Brysbaert et al.; свободно доступные данные).
Это общий список уведомлений пакета, не утверждение об участии каждого источника
именно в русской таблице.
[NOTICE upstream, закреплённый commit](https://github.com/rspeer/wordfreq/blob/42233e6c36ce792031bcccfa17cdd0cec9af5fa7/NOTICE.md).
Этот NOTICE проверен отдельно; commit соответствует тегу v3.2, не выдаётся за
исходник установленного пакета 3.1.1. Установленные METADATA/LICENSE сохраняются
рядом с экспортом. Второй независимый источник частот пока не сравнивался.

## Воспроизведение

Из корня проекта, с уже установленным `uv`:

```bash
~/.local/bin/uv venv --python /usr/bin/python3 rechprav/artifacts/resources-venv
~/.local/bin/uv pip install --python rechprav/artifacts/resources-venv/bin/python -r rechprav/scripts/requirements-resources.txt
rechprav/artifacts/resources-venv/bin/python rechprav/scripts/prepare_resources.py rechprav/artifacts/opencorpora-wordfreq
```

Последняя команда требует нового каталога; существующий экспорт не перезаписывает.
Установка пакетов требует сети; сам экспорт её не использует. Проверено с Python
3.13.5. Закреплены и проверяются версии всех 11 зависимостей. SHA256 исходных файлов
пакетов, экспортов, версии и параметры сохраняются в `manifest.json`.
Проверка SHA256 экспортов перед опытом обнаруживает подмену данных; это не lockfile
хешей дистрибутивов PyPI. Если результат экспорта отличается от зафиксированного
manifest, нельзя считать его тем же ресурсом.

Большие воспроизводимые данные и окружение находятся в игнорируемом Git каталоге
`rechprav/artifacts/`. В Git остаются код экспорта, версии, метаданные, результаты
опыта и ссылки/атрибуция. Экспорты словоформ и частот — преобразования соответствующих
CC BY-SA данных; при их отдельном распространении нужно приложить лицензии и
upstream-уведомления, а также описание преобразований.
