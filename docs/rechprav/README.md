Актуальный статус и порядок дальнейшей работы — в [следующих шагах](next-steps.md).

[обзоре](results-review.md); подробная последовательность решений — в

[Общий план](implementation-plan.md) остаётся открытым: реальной независимой
оценки ASR и автоматического обучения из подтверждённых правок ещё нет.
Нумерованные документы `006`–`020` — зафиксированные до опытов протоколы, а не
список текущих задач. Опыты по ним проведены; результаты хранятся в
`rechprav/experiments/`. В частности, `014`–`020` реализованы как отдельные
инструменты и проверки, но не как пользовательский поток в приложении.
Протоколы оставлены рядом с результатами для проверки происхождения решений.
Исходный пользовательский `first-plan.md` есть в рабочей папке, но не добавлен
в Git; в чистой копии проекта ссылки на него будут недоступны.
